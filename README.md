# Web Application Files Collection

This web application provides access to multiple files related to storytelling, ethical dilemmas, personal description, SVG graphics, geolocation data, economic forecasts, and licensing.

## Files Included

- `ashravan.txt`: A short story describing the fate of Ashravan after the events of Shai's restoration, building up to a dramatic climax.
- `dilemma.json`: JSON data posing an ethical dilemma faced by autonomous vehicles, with different scenarios.
- `about.md`: A brief personal descriptor in three words.
- `pelican.svg`: An SVG illustration of a pelican riding a bicycle.
- `restaurant.json`: Details of a recommended restaurant in Chennai, including location and cuisine.
- `prediction.json`: Fictional forecast of the Federal Funds Rate in December 2025.
- `LICENSE`: MIT License details.
- `uid.txt`: An attachment UID.

This site is designed for demonstration purposes, showcasing static files accessible via links, and is made fully responsive with Tailwind CSS for modern compatibility.
